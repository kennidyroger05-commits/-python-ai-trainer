Based on `feature/v2-debug-training`. Preserves all forty V2 missions and adds four connected ten-stage projects: model router, fictional AI API client, model evaluation and training-log interpretation. Also adds eight three-stage professional debugging scenarios, a six-stage testing introduction, layered bilingual explanations, optional concept review, evidence-only competency cards and an honestly labeled local Markdown portfolio.
